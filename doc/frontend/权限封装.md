# 权限封装

权限分两层：路由级（页面）与按钮级。路由级由后端下发的菜单决定，按钮级用 `hasPermission` 判断。

## 固定路由与拦截器

`src/router/index.js` 定义固定路由（`defaultRouterList`）：`/` 重定向到 `/dashboard`、`/dashboard`、`/login`、`/personal`、`/:pathMatch(.*)*`（404）。这些路由不依赖权限，随应用一起注册。

初始化时用拦截器包装路由：

```js
export default intercept(router)
```

拦截逻辑在 `src/router/interceptor.js`，注册了两个 `beforeEach` 与一个 `afterEach`（按注册顺序执行）。

### 动态路由加载（第一个 beforeEach）

有 token 且 app store 尚未加载菜单时，调用 `useAppStore().loadRoutes()` 拉取并注册动态路由，然后 `return to.fullPath` 触发重新导航，使新路由生效。

### 登录与用户信息（第二个 beforeEach）

1. `NProgress.start()`。
2. 有 token 且访问 `/login`：重定向到 `/`。
3. 有 token：`await useUserStore().loadInfo()` 加载用户信息；失败则 `removeToken()` 并跳 `/login?redirect=<原路径>`。
4. 无 token 且在白名单（`['/login']`）：放行。
5. 其余：跳 `/login?redirect=<原路径>`。

`afterEach` 调用 `NProgress.done()`。

纯前端模式（`VITE_ONLY_UI`）下自动 `setToken('only_ui')`。

## 菜单与权限数据来源

| 数据 | 接口 | 存储 |
|---|---|---|
| 动态路由 / 菜单树 | `GET /auth/router` | `useAppStore().menus`，并转为 vue-router 路由 |
| 用户信息、角色、权限 | `GET /auth/own` | `useUserStore()` 的 `info` / `roles` / `permissions` |

`useAppStore().loadRoutes()` 把后端菜单树映射为路由：一级菜单挂 `Layout`，子菜单组件按 `component` 字段从 `import.meta.glob('@/views/**')` 解析，一级路由通过 `$router.addRoute` 注册。同一份 `menus` 供侧边栏（`src/layouts/sidebar/SidebarContent.vue`）渲染菜单。

## 页面级权限

由动态路由保证：后端不下发的菜单不会注册成路由，访问即落到 404。前端不做额外的页面级判断。

## 按钮级权限

`useUserStore().hasPermission(codes)`：

- `roles[0].level === 0`（超管）恒为 `true`。
- `codes` 为空返回 `false`。
- 数组：`permissionCode` 命中任一即通过。
- 字符串：`permissionCode` 包含即通过。

`permissionCode` = 所有 `roleCode` + 所有 `permission`（过滤空串）。

典型用法是在 `MoneyCrud` 的 `optShow` / `rowOptDisabled` 中按权限显隐/禁用按钮：

```js
const userStore = useUserStore()

const moneyCrud = ref(new MoneyCrud({
    optShow: {
        checkbox: userStore.hasPermission(['user:edit', 'user:del']),
        add: userStore.hasPermission('user:add'),
        edit: userStore.hasPermission('user:edit'),
        del: userStore.hasPermission('user:del'),
    },
    rowOptDisabled: {
        del: (row) => row.roles[0].level <= userStore.level,
    },
}))
```

仓库内没有权限指令（无 `v-permission`），按钮级判断统一用 `hasPermission` 函数式表达。

## 无权限时的处理

| 场景 | 处理 | 位置 |
|---|---|---|
| 接口返回 401 | 提示登录过期并 `logout()` | `src/api/axios.js` |
| 接口返回 403 | 提示无权限 | `src/api/axios.js` |
| 无 token 访问受保护页 | 跳 `/login?redirect=<原路径>` | `src/router/interceptor.js` |
| `loadInfo` 失败 | 清除 token 并跳登录 | `src/router/interceptor.js` |
| 访问未授权路由 | 匹配 404 | `src/router/index.js` |
